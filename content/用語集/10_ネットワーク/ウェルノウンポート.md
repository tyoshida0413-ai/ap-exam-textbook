# ウェルノウンポート

> **0〜1023の、主要なサービスに割り当てられた予約済みポート番号**。

## なぜそうなるのか

「Webサーバは80番で待つ」と世界中で決めておかないと、クライアントは何番につなげばよいか分かりません。
そのために予約されているのがウェルノウンポートです。

| ポート | サービス |
|---|---|
| 20/21 | FTP |
| 22 | SSH |
| 23 | telnet |
| 25 | SMTP |
| 53 | DNS |
| 80 | HTTP |
| 443 | HTTPS |

1024番以降は、クライアント側が通信ごとに一時的に使う番号（エフェメラルポート）に使われます。

## 試験での問われ方

- **80番（HTTP）と443番（HTTPS）は暗記必須**。ファイアウォール設定問題で頻出
- 「0〜1023の範囲を何と呼ぶか」→ **ウェルノウンポート**
