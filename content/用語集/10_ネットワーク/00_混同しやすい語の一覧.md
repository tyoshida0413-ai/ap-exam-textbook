# ネットワーク 混同しやすい語の一覧

> **2つの使い方がある**
> (1) **学習用**：試験で狙われるのは「似た語の取り違え」。ここだけ潰せば失点が大きく減る
> (2) **作業用**：用語集を書くときの設計図（→ 3章の難語リストが執筆の優先順位になる）

> **この分野の大原則**
> ネットワークの選択肢は、**「それは何層の話か」を判定できれば半分が切れます。**
> 対比を覚える前に、まず**層**を確認する癖をつけてください（→ 教科書 [[10_ネットワーク]] の 0.3 節）。

## 1. 最重要の混同ペア（ここを間違えると失点が大きい）

| 対比 | 決定的な違い | ひっかけの出方 |
|---|---|---|
| [[TCP]] ↔ [[UDP]] | **接続を確立し再送する**／**しない**。確実さ／**低遅延** | 「リアルタイム音声に適するのは」でTCPを混ぜる |
| [[CSMA-CD\|CSMA/CD]] ↔ [[CSMA-CA\|CSMA/CA]] | **D**etection＝衝突を**検出してから**対処（有線）／**A**voidance＝**事前に避ける**（無線） | 「無線LANの方式は」でCDを混ぜる。**最頻出** |
| [[MACアドレス]] ↔ [[IPアドレス]] | **製造時に固定・隣まで**／**つなぐ場所で変わる・最終目的地まで**。ルータを越えると**MACだけ書き換わる** | 「経路上で変化するのはどちらか」 |
| [[NAT]] ↔ NAPT | IPアドレスだけ変換／**ポート番号も**変換。1つのグローバルIPで**複数台**が同時に出られる | 「1つのIPで複数台が同時通信できるのは」 |
| [[RIP]] ↔ [[OSPF]] | **ホップ数**だけで選ぶ（回線速度を見ない・最大15）／**コスト**で最短経路を計算 | 「低速回線を選んでしまう欠点があるのは」 |
| [[OSPF]] ↔ [[BGP]] | 組織**内部**の経路（IGP）／組織**間**＝AS間の経路（EGP） | 「インターネットの基幹で使われるのは」 |
| フロー制御 ↔ 輻輳制御 | **相手**（受信側）の処理能力に合わせる／**途中の回線**の混雑に合わせる | 「誰の都合に合わせているか」を入れ替える |
| [[POP3]] ↔ [[IMAP4]] | **端末にダウンロードして消す**／**サーバに置いたまま**読む | 「複数端末で同じメールを見たいときは」 |
| [[ブリッジ]] ↔ [[ルータ]] | **MACアドレス**（2層）で中継／**IPアドレス**（3層）で中継 | 装置と層を入れ替える |
| [[ルータ]] ↔ [[L3スイッチ]] | 機能は同じ。**ソフトウェア中心・異種回線の接続**／**専用ハードで高速・LAN内** | 「機能の違い」として出したら誤り。違いは**速度と用途** |
| [[ゲートウェイ]] ↔ [[ルータ]] | **プロトコルを変換**して接続／同じプロトコルで経路制御 | 「プロトコルが異なる網をつなぐのは」 |
| フォワードプロキシ ↔ リバースプロキシ | **クライアント**の代理／**サーバ**の代理。目的も正反対 | 「負荷分散やSSL処理を肩代わりするのは」 |
| [[広域イーサネット]] ↔ [[IP-VPN]] | **レイヤ2**で接続・経路設計は**自社**／**レイヤ3**で接続・経路制御は**事業者** | 自由度の所在を入れ替える |
| [[優先制御]] ↔ [[帯域制御]] | **遅延に敏感な通信を先に**流す／**種類ごとに使える帯域を割り当てる** | 解決したい問題を入れ替える |
| [[伝送効率]] ↔ [[回線利用率]] | 回線速度のうち**実データに使える割合**／回線能力のうち**実際に使われている割合** | 計算問題で分母を入れ替える |
| 遅延 ↔ [[ジッタ]] | **届くまでの時間**／**到着間隔のばらつき**。音声が途切れるのはジッタ | 「音声がぶつ切りになる原因は」 |
| [[HTTP-2\|HTTP/2]] ↔ [[HTTP-3\|HTTP/3]] | どちらもTCP上／**HTTP/3はUDP（QUIC）上** | 「UDPを使うのはどちらか」 |
| [[STP]] ↔ [[リンクアグリゲーション]] ↔ [[VRRP]] | **ループを遮断**（L2）／**複数回線を束ねる**（L2）／**ルータを冗長化**（L3） | 3つの目的を入れ替える |
| [[SDN]] ↔ [[NFV]] | **制御機能と転送機能を分離**して一元制御／**専用機器の機能をソフトウェア化** | 「機器をソフトウェアで置き換えるのは」 |
| [[パケット交換]] ↔ 回線交換 | 分割して**共有**する／通信路を**占有**する | 「常に速いのはパケット交換」＝誤り |

## 2. セットで理解すべき語のかたまり

### (A) 中継装置は「見る層」の順で覚える

```
リピータ（1層・何も見ない）→ ブリッジ（2層・MAC）→ ルータ（3層・IP）→ ゲートウェイ（4〜7層・プロトコル変換）
```

[[リピータ]] ／ [[ブリッジ]] ／ [[ルータ]] ／ [[ゲートウェイ]] ／ [[L3スイッチ]]
**深く見るほど賢い判断ができるが、その分だけ時間がかかる**という一直線の関係。

### (B) アドレス計算は3点セットで出る

[[サブネットマスク]] ／ [[CIDR]] ／ [[ホスト数の計算]] ／ [[ブロードキャストアドレス]]

> **ホスト数 ＝ 2のn乗 − 2**（nはホスト部のビット数）。
> **−2 の理由**：ホスト部が**すべて0＝ネットワークアドレス**、**すべて1＝ブロードキャストアドレス**で、
> どちらも機器には割り当てられないため。**この2を引き忘れる誤答が必ず選択肢にある。**

### (C) TCPが「確実」である4つの仕組み

[[3ウェイハンドシェイク]]（接続確立）／ 確認応答と再送 ／ 順序制御 ／ [[ウィンドウ制御]]（量の調整）

> [[UDP]]はこの**すべてを持たない**。だから速い。**優劣ではなく用途の違い**。

### (D) 名前とアドレスを結ぶ3つ

[[DNS]]（名前 → IPアドレス）／ [[ARP]]（IPアドレス → MACアドレス）／ [[DHCP]]（設定を配る）

> **どの層をつなぐ変換なのか**で区別する。ARPは**3層と2層の橋渡し**。

### (E) 経路制御プロトコルは「何を基準に選ぶか」で並ぶ

[[RIP]]（ホップ数）→ [[OSPF]]（コスト＝回線速度）→ [[BGP]]（AS間のポリシー）
関連：[[ルーティングテーブル]] ／ [[デフォルトゲートウェイ]]

### (F) 止めないための冗長化

[[単一障害点]] → [[STP]]（ループ遮断）／[[リンクアグリゲーション]]（束ねる）／[[VRRP]]（ルータ冗長化）

> **なぜループが危険か**：L2のフレームには**TTLが無い**ので、
> ループに入ったブロードキャストは**永久に増え続ける**（[[ブロードキャストストーム]]）。

### (G) 無線は「見えないから起きる問題」で覚える

[[CSMA-CA\|CSMA/CA]]（衝突を検出できないので避ける）／[[SSID]]（ステルスは対策にならない）／
[[IEEE 802.11]]（2.4GHz＝遠いが干渉／5GHz＝速いが障害物に弱い）／[[ローミング]] ／ [[メッシュネットワーク]]

### (H) モバイルとIoTは「何を優先するか」で分かれる

[[5G]]（高速大容量・低遅延・多数同時接続）↔ [[LPWA]]（**低速でよいから低消費電力と長距離**）
関連：[[LTE]] ／ [[テザリング]] ／ [[MQTT]] ／ [[センサーネットワーク]]

### (I) Webの状態管理

[[HTTP]]は**ステートレス**（毎回忘れる）→ [[Cookie]]（番号札を客に持たせる）→ [[セッション管理]]（台帳は店が持つ）

> **セッションIDに推測困難性が要る理由**がここから出る。番号札を拾われるとなりすませる。

### F3で見つかった問題（2026-08-03・次分野の参考に）

| 種類 | 内容 |
|---|---|
| **誤り** | [[STP]]でTTLを`[[MTU\|TTL]]`とリンクしていた（TTLとMTUは別概念。引きたい人が違うページへ飛ぶ）／「IPアドレスのパケット」という不正確な表現 |
| **誤り** | [[MTU]]のページにTTLの説明が同居し、主題がぼけていた（1ファイル1単語の原則に反する） |
| **欠落** | [[CIDR]]に**経路集約**が無い／[[UDP]]に**1対多の同報通信**（ブロードキャスト・マルチキャスト）が無い／[[RIP]]に**収束の遅さ**が無い／[[OSPF]]に**エリア**が無い／[[BGP]]に**パスベクトル型**が無い／[[セッション管理]]に**Secure・HttpOnly属性**が無い／[[HTTP-3\|HTTP/3]]に**接続確立の速さとコネクション移行**が無い／[[TCP]]で**フロー制御と輻輳制御の区別**が薄い |
| **表現** | [[QoS]]の一言定義が「品質を**保証**する」（ベストエフォートとの対比で誤解を招く）→「確保する」に変更 |

> **傾向**：F2（Sonnet）の記述に**技術的な誤りはほぼ無い**が、
> **「試験に出るのに書かれていない」欠落**が難語に集中した。
> F3では内容の正誤より「**その語で問われる論点が揃っているか**」を見るとよい。
