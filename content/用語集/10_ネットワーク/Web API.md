# Web API

> **HTTPを介して外部から機能を呼び出せるインタフェース**。
> REST方式が主流。

## 日常のたとえ

レストランの注文カウンター。厨房（システムの中身）に立ち入らせず、
決められた注文の仕方でだけ受け付けます。中の作り方を知らなくても、
正しい注文の形式さえ守れば料理（データ）が出てきます。

## なぜそうなるのか

**REST**（REpresentational State Transfer）方式は、HTTPのGET・POSTなどをそのまま使い、
主に**JSON**でデータをやり取りする、単純・軽量な方式です。

## 混同しやすい語

| 語 | 決定的な違い |
|---|---|
| [[SOAP]] | あちらは**XML**を使う厳格な規約。Web API（REST）は**JSON中心で軽量** |

- 「HTTPを介して外部から機能を呼び出す方式は」→ **Web API**（REST）
