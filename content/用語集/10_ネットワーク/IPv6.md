# IPv6

> **128ビットのアドレスを持つIP**。アドレス枯渇を解決し、IPsecを標準で備える。

## なぜそうなるのか

[[NAT]]は延命策であって、根本解決ではありません。根本解決がIPv6です。

| | IPv4 | IPv6 |
|---|---|---|
| アドレス長 | 32ビット（約43億個） | **128ビット**（実質枯渇しない） |
| IPsec | 任意 | **標準で組み込み** |
| ヘッダ | 可変長で複雑 | **固定長で単純**（ルータの処理が速い） |
| ブロードキャスト | あり | **なし**（マルチキャストで代替） |
| MACアドレスの解決 | [[ARP]] | NDP（近隣探索プロトコル） |

**なぜ128ビットもの長さにしたのか。** 「枯渇したらまた変える」を繰り返さないため、
移行に長い年月がかかることを見越して、当面二度と足りなくならない桁にしてあります。

## 試験での問われ方

- 「IPv6の特徴として適切なものは」→ **アドレス長128ビット／IPsec標準サポート／ヘッダの簡素化**
- ひっかけ：「IPv4より通信速度が速い」＝誤り（速度の規格ではない）
