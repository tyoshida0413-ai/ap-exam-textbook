# 関係代数

> **射影・選択・結合・和・差・直積などで関係を操作する理論体系**。

## なぜそうなるのか

表を扱う操作は突き詰めると「行を選ぶ」「列を選ぶ」「表をつなぐ」の3つです。
これに数学的な名前を付けたものが関係代数で、**SQLの土台**になっています。

| 演算 | 何をするか | SQLでの対応 |
|---|---|---|
| [[射影]] | 指定した列を取り出す（縦に切る） | SELECT 列名 |
| 選択 | 条件に合う行を取り出す（横に切る） | WHERE |
| 結合 | 2つの表を共通の列でつなぐ | JOIN |
| 和・差・積 | 表どうしを合わせる／引く／両方にあるものを取る | UNION・EXCEPT・INTERSECT |
| [[直積]] | すべての行の総当たりの組み合わせ | CROSS JOIN |

## 試験での問われ方

- 8演算とSQL構文の対応を問う出題
- 直積と結合の関係（結合＝直積＋選択）を問う出題
