# 関係代数

> **関係（表）に演算を施して、新しい関係を得る理論体系**。SQLの土台。
> 集合演算4つと関係演算4つ、合わせて**8つの演算**からなる。

## なぜそうなるのか

表を扱う操作は、突き詰めると「行を選ぶ」「列を選ぶ」「表をつなぐ」に集約されます。
これに数学的な定義を与えたものが関係代数です。
**演算の結果もまた表になる**ため、演算を次々につなげられるのが利点です。

### 集合演算（4つ）

和・差・共通は、**列の構成が同じ表どうし**でなければ実行できません（これを**和両立**といいます）。

| 演算 | 何をするか | SQL |
|---|---|---|
| 和 | どちらかにある行を集める | UNION |
| 差 | 一方にあって他方に無い行 | EXCEPT |
| 共通（積集合） | **両方にある行だけ** | INTERSECT |
| [[直積]] | 全行の**総当たりの組み合わせ** | CROSS JOIN |

> **直積だけは和両立が不要**です。列の構成が違う表どうしを組み合わせる演算だからです。
> 「積」の字が共通（積集合）と紛らわしいので、**直積は総当たり、共通は重なり**と覚えます。
> 直積の行数は**掛け算**（m行 × n行）、列数は**足し算**になります。

### 関係演算（4つ）

| 演算 | 何をするか | SQL |
|---|---|---|
| 選択 | 条件に合う**行**を取り出す（横に切る） | WHERE |
| [[射影]] | 指定した**列**を取り出す（縦に切る） | SELECT 列名 |
| 結合 | 2つの表を共通の列でつなぐ | JOIN |
| 商 | 「**すべての◯◯を満たす**」ものを取り出す | 対応する構文はない |

**商**は「全科目を履修している学生を求める」ような問いに対応する演算です。
出題は多くありませんが、**8演算を数えさせる問題があるため名前だけは必要**です。

### 結合は直積と選択でできている

```
結合 ＝ 直積（総当たりを作る）→ 選択（共通列の値が一致する行だけ残す）
```

この分解を知っていると、結合の結果行数を数える問題で迷いません。

## 混同しやすい語

| 語 | 決定的な違い |
|---|---|
| [[射影]] と 選択 | **列**を絞る／**行**を絞る。入れ替えるひっかけが最頻出 |
| [[直積]] と 共通 | **総当たり**で行数が掛け算になる／**両方にある行**だけが残る |
| 関係論理 | 「どう求めるか」を書く関係代数に対し、「**何が欲しいか**」を書く体系。SQLは両方の性質を持つ |

## 試験での問われ方

- 8演算とSQL構文の対応を問う出題
- **結合＝直積＋選択**の関係を問う出題
- 2つの表を示し、**演算後の行数・列数を答えさせる**出題
- ひっかけ：選択と射影の説明を入れ替える
