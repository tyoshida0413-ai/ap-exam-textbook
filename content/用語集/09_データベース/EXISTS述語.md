# EXISTS述語

> **副問合せの結果が1行でも存在するかを判定する述語**。

## なぜそうなるのか

「該当する行が1件でもあるか」だけを見るので、見つかった時点で探索を打ち切れます。
件数が多い場合に有利です。`NOT EXISTS`は「1件もないか」を判定し、
「すべてを満たすものを探す」という問合せを書くときにも使われます。

```sql
SELECT 部門名 FROM 部門表 B
WHERE EXISTS (SELECT * FROM 社員表 S WHERE S.部門コード = B.部門コード);
```

## 試験での問われ方

- 「副問合せの結果が存在するかだけを判定する述語は」→ **EXISTS**
