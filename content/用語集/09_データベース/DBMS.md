# DBMS

> **データの定義・操作・制御を一元的に行うデータベース管理システム**。

## なぜそうなるのか

図書館の本を利用者が勝手に出し入れすると、本は行方不明になり目録も合わなくなります。
だから図書館にはカウンターがあり、探す・貸出を記録する・順番を調整するのは司書の仕事です。

この司書にあたるのがDBMSです。利用者やアプリケーションは**データファイルを直接触らず**、
必ずDBMS越しに頼みます。

| DBMSがやること | 何のためか |
|---|---|
| データの定義と格納 | どんな表があるかを管理し、実際の記録を保管する |
| 問い合わせの処理 | SQLを受け取り、効率のよい取り出し方を自分で考える |
| 同時実行の制御 | 複数人が同時に使っても矛盾しないよう順番を調整する |
| 障害からの回復 | 障害が起きても、直前の正しい状態に戻す |
| 機密の保護 | 誰がどの表を見てよいかを管理する |

## 試験での問われ方

- 「データの定義・操作・制御を一元的に行うシステムは」→ **DBMS**
- DBMSが担う5つの役割を挙げさせる出題
