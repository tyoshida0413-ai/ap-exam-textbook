# 射影

> **関係から必要な列だけを取り出す演算**（縦に切る）。
> 行を取り出す演算が**選択**（横に切る）。

## 日常のたとえ

名簿から「氏名の列だけ」を書き写すのが射影、
「営業部の人の行だけ」を書き写すのが選択です。
**縦に切るか、横に切るか**の違いだけですが、試験ではここが最も多く狙われます。

## なぜそうなるのか

```
【元の表】
社員番号  氏名  部署   給与
 1001    田中  営業    300
 1002    佐藤  経理    350
 1003    鈴木  営業    300

射影（部署, 給与） → 営業300 ／ 経理350        ← 列を絞る（縦）
選択（部署＝営業） → 1001田中営業300
                    1003鈴木営業300           ← 行を絞る（横）
```

### 射影は重複行を取り除く

上の射影で、1001と1003はどちらも「営業・300」になります。
関係代数では**関係は集合**なので、まったく同じ行が2つ存在することは許されません。
したがって**射影の結果からは重複行が自動的に取り除かれ、2行になります**。

一方、**SQLの `SELECT 部署, 給与` は重複を残して3行返します**。
理論どおりに重複を消したいときは `SELECT DISTINCT` と書きます。
**関係代数とSQLで結果が違う**のはここで、行数を答えさせる問題で差がつきます。

## 混同しやすい語

| 語 | 決定的な違い |
|---|---|
| 選択 | あちらは**行**を絞る（横に切る）。射影は**列**を絞る（縦に切る） |
| [[関係代数]] | 射影はその8演算のうちの1つ |
| [[直積]] | あちらは**行数が掛け算で増える**。射影は列が減るだけで行は増えない |

## 試験での問われ方

- 「指定した条件を満たす**行**を取り出す演算は」→ **選択**。射影を混ぜる誤答が定番
- 「選択」と「射影」の説明を入れ替えるひっかけが**最頻出**
- 射影の結果行数を問う出題 → **重複を除いた行数**で答える
