# CSIRT

> Computer Security Incident Response Team。セキュリティインシデントに対応する専門組織。検知・分析・復旧・再発防止を担う。

## 日常のたとえ

**消防隊**です。火事（インシデント）が起きたら出動し、初期消火・被害拡大の防止・鎮火後の原因調査までを担います。
普段から巡回して火の元をチェックする「見回り担当」（[[SOC]]）とは役割が異なります。

## なぜそうなるのか

CSIRTは、セキュリティインシデントが発生した際の**対応の司令塔**です。
インシデント対応は次のフェーズで進みます。

```
準備 → 検知・分析 → 封じ込め・根絶・復旧 → 事後対応（教訓の反映）
```

CSIRTはこの一連のプロセスを主導し、**社内外の関係者との調整**も担います。
（例：経営層への報告、外部機関との連携、必要に応じて[[JPCERT-CC|JPCERT/CC]]への相談）

**「監視して見つける」役割はSOCが担い、「見つかった後にどう動くか」をCSIRTが担う**、
という役割分担で理解すると整理しやすくなります。

## 混同しやすい語

| 語 | 決定的な違い |
|---|---|
| [[SOC]] | SOCは**監視・検知**（ログを24時間見張る）。CSIRTは**対応・調整**（見つかった後に動く）。役割が入れ替わりやすい最頻出ペア |
| [[JPCERT-CC|JPCERT/CC]] | CSIRTは**組織内**のインシデント対応チーム。JPCERT/CCは**国内外の調整役**を担う代表的なCSIRT（社会全体でみると「CSIRTの一種」にあたる） |

## 試験での問われ方

- 「CSIRTの役割として適切なものは」→ **インシデント発生時の対応方針を決定し、外部機関と調整する**
- 「セキュリティ機器のログを常時監視し、脅威を検知する」という選択肢は**SOC**の説明であり誤り
