# セキュアプログラミング

> 脆弱性を作り込まないコーディング作法。境界検査や適切なエラー処理を含む。

## 何をするか

プログラムを書く段階から、脆弱性を生まないよう配慮する作法の総称です。

| 原則 | 内容 |
|---|---|
| [[入力値検証]] | 型・長さ・範囲・書式をサーバ側で必ず検証する |
| 出力時のエスケープ（[[サニタイジング]]） | 表示先の文脈に応じて無害化する |
| [[プレースホルダ]]の使用 | SQL文の構造と値を分離する |
| エラー処理 | 内部情報（スタックトレース、SQL文、パス）を利用者に見せない |
| フェールセーフ | 異常時は安全側に倒す。明示的に許可したものだけ通す |
| 境界検査 | [[バッファオーバフロー]]を防ぐため、確保した領域を超える入力を許さない |

## 試験での問われ方

- 個別の対策（プレースホルダ、エスケープ、入力値検証等）が、この総称の一部として問われる
