# 魔の川・死の谷・ダーウィンの海

> 研究から開発、事業化、産業化へ進む過程で技術が直面する3つの障壁。研究→開発の壁が「魔の川」、開発→事業化の壁が「死の谷」、事業化→産業化（市場定着）の壁が「ダーウィンの海」。

## 日常のたとえ

大学の研究室で画期的な新素材が発見されたとします。しかし、その発見が実際に商品として店頭に並ぶまでには、いくつもの関門があります。「研究成果を実際に使える技術に落とし込めるか」「試作品を作る予算が続くか」「量産して市場に出しても他社との競争に負けないか」。それぞれの関門で、どれだけ優れた発見でも埋もれてしまうことがあります。

## なぜそうなるのか

優れた技術が生まれても、そのまま事業の成功につながるとは限りません。技術が世に出るまでの過程には、順番に3つの関門があります。

```
研究 → 【魔の川】 → 開発 → 【死の谷】 → 事業化 → 【ダーウィンの海】 → 産業化
```

| 関門 | どこからどこへの壁か | つまずく理由の例 |
|---|---|---|
| **魔の川** | 研究 → 開発 | 研究成果を実用化できる技術に落とし込む目処が立たず、開発予算が付かない |
| **死の谷** | 開発 → 事業化 | 試作はできても、量産・販売するための投資判断が下りない |
| **ダーウィンの海** | 事業化 → 産業化（市場定着） | 商品化はできても、既存の競合製品や代替品に競り負けて市場に定着できない |

**それぞれの壁で「足止めされる理由」が異なる**点が重要です。魔の川は主に**技術面の目処**、死の谷は主に**投資判断**、ダーウィンの海は主に**市場競争**でつまずきます。この3つの関門をどう越えるかを扱うマネジメント領域が、[[MOT]]（技術経営）です。**「良い技術を作る力」と「その技術で儲ける力」は別のスキルである**という問題意識が、この3段階の比喩の背景にあります。

## 混同しやすい語

| 語 | 決定的な違い |
|---|---|
| [[イノベーションのジレンマ]] | 魔の川・死の谷・ダーウィンの海は**技術が世に出るまでの障壁**（順を追って越えるべき壁）／イノベーションのジレンマは**既に成功している優良企業が新技術への対応で遅れる現象**で、障壁の話ではなく因果の話 |
| [[キャズム]] | 3つの壁は**事業化されるまで**の関門／キャズムは**事業化された後、市場に普及していく過程**で生じる溝。時間軸上の位置が異なる |

## 試験での問われ方

- 「魔の川・死の谷・ダーウィンの海の順序として、適切なものはどれか」→ **研究→開発の間が魔の川、開発→事業化の間が死の谷、事業化→産業化の間がダーウィンの海**
- ひっかけ：3つの関門の順序を入れ替える、または「事業化」と「産業化（市場定着）」を同じ段階として扱う選択肢。**ダーウィンの海は「事業化した後、市場で生き残れるか」の壁**である点に注意
- 「MOT（技術経営）がこの3つの関門を扱う理由」を問う設問も定番
