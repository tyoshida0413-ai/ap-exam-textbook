# 経営戦略・技術戦略 混同しやすい語の一覧

> **2つの使い方がある**
> (1) **学習用**：試験で狙われるのは「似た枠組みの取り違え」。ここだけ潰せば失点が大きく減る
> (2) **作業用**：用語集を書くときの設計図（→ 3章の難語リストが執筆の優先順位になる）

---

## 1. 最重要の混同ペア（ここを間違えると失点が大きい）

| 対比 | 決定的な違い | ひっかけの出方 |
|---|---|---|
| [[SWOT分析]] ↔ [[VRIO分析]] | SWOTの機会（O）は**外部環境**／VRIOの経済価値（V）は**内部資源の評価軸** | 「機会」と「経済価値」を同じ意味として扱う選択肢 |
| [[PPM]] ↔ [[成長マトリクス]] | PPMは**市場成長率×占有率**で既存事業の**資源配分**を判断／成長マトリクスは**製品×市場の新旧**で**事業拡大の方向**を判断 | 花形・金のなる木と、多角化・新市場開拓を入れ替える |
| [[M&A]] ↔ [[TOB]] ↔ [[MBO]] | M&Aは**合併・買収の総称**／TOBは**市場外で条件を公表して買い集める手法**／MBOは**経営陣自身が買い取る**手法 | 「TOBは経営陣が行う」「MBOは外部企業が行う」と主語を入れ替える |
| [[CRM]] ↔ [[SCM]] ↔ [[ERP]] | CRMは**顧客情報**／SCMは**調達から販売の供給連鎖**／ERPは**経営資源全体**を管理対象とする、**管理範囲の広さが違う** | 管理対象を入れ替える。「ERPは顧客関係管理システムである」など |
| [[ブルーオーシャン戦略]] ↔ コストリーダーシップ戦略 | ブルーオーシャンは**競争のない市場を創る**／コストリーダーシップは**既存市場で価格勝負する** | 「何と戦うか」を問う設問で両者を混同させる |
| [[プロダクトイノベーション]] ↔ プロセスイノベーション | プロダクトイノベーションは**新しい製品を生む**／プロセスイノベーションは**製造工程を革新する** | 「工程の革新はプロダクトイノベーションである」と入れ替える |
| [[イノベーター理論]] ↔ [[キャズム]] | イノベーター理論は**採用の早さで消費者を5層に分類**する枠組み／キャズムは**初期市場と主流市場の間にある溝そのもの** | キャズムを「消費者の分類の1つ」として扱う選択肢 |

## 2. セットで理解すべき語のかたまり

**バラバラに覚えると必ず混ざる。かたまりごと、因果の順で理解する。**

### (A) 目標の具体化の階層

```
戦略目標（ありたい姿）
   ↓
KGI（最終的な数値目標）
   ↓
CSF（達成のために特に重要な要因・活動）
   ↓
KPI（日々測る中間指標）
```
※ KGI・KPI は単語リストに独立エントリを持たないため、[[CSF]] のファイル内でまとめて説明する。

**[[バランススコアカード]]** はこの階層を「財務・顧客・内部ビジネスプロセス・学習と成長」の4視点に広げたもの。
**財務は結果（遅行指標）で、他の3視点の変化が先に現れる**という因果の向きがひっかけの定番。

### (B) 知識創造のサイクル

```
ナレッジマネジメント（個人の暗黙知を組織の力に変える取り組み全体）
   ↓ その中核理論が
SECIモデル（共同化 → 表出化 → 連結化 → 内面化）
```

### (C) イノベーションが普及するまでの3つの障壁

```
研究 → 【魔の川】 → 開発 → 【死の谷】 → 事業化 → 【ダーウィンの海】 → 産業化
```
資金・人材が続かず頓挫する場所がそれぞれ違う（研究→開発／開発→事業化／事業化→産業化での淘汰）。

### (D) 普及の順序とつまずき

```
イノベーター理論：イノベータ → アーリーアダプタ → 【キャズム＝深い溝】 → アーリーマジョリティ → レイトマジョリティ → ラガード
```
**イノベーションのジレンマ**は別の現象（優良企業が既存事業を優先するあまり破壊的技術への転換に遅れる）で、
上記の普及順序そのものとは区別する。

### (E) 企業を拡大・統合する3つの手法

```
M&A（合併・買収の総称。友好的にも敵対的にもなりうる）
TOB（買付け条件を公表して市場外で株式を買い集める、M&Aの一手法）
MBO（経営陣が自社株式・事業を買い取って独立する、対象が"外部"ではなく"自社"である点が特殊）
```

### (F) 統合管理システムの管理範囲

```
CRM（顧客情報）  ⊂ 狭い
SCM（調達〜販売の供給連鎖）
ERP（企業の経営資源全体） ⊃ 広い
```

## 3. 難語リスト（フェーズ3のレビュー対象）

**全48語中、次の22語（約46%）を「難」とする。** 残り26語は「易」。
判定基準は `00_引き継ぎ.md` の6章に従う。

> **⚠️目安（難は全体の2〜3割程度）を大きく上回っている。**
> セキュリティ分野の実績は140語中44語（約30%）だった。この分野が46%と高くなったのは、
> 経営戦略・技術戦略が「似たフレームワークの対比」で問われる語が本質的に密集する分野だからである
> （SWOT↔VRIO、PPM↔成長マトリクス、M&A↔TOB↔MBO、CRM↔SCM↔ERP など、単体では易でも
> ペア・セットで扱うと難になる語が多い）。無理に目安へ合わせて対比の要となる語を易に落とすと、
> F3（Opusレビュー）の対象から漏れて試験の頻出ひっかけを取りこぼすため、基準どおり判定した。
