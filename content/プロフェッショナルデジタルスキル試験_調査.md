# プロフェッショナルデジタルスキル試験（PD試験）とは

> **この資料の位置づけ**
> 応用情報技術者試験の**廃止後（2027年度〜）の受け皿**にあたる新試験の調査メモ。
> **すべて「案」の段階**であり、試験区分名にも「（仮称）」が付いている。確定情報ではない。
> 関連：`応用情報技術者試験全体像.md` 10章

---

## 1. 一言でいうと

**現行の高度試験（レベル4）9区分と応用情報技術者試験を解体し、3つに束ね直したもの。**

- 正式名（仮称）：プロフェッショナルデジタルスキル試験
- 英名：Professional Digital Skills Examination
- 区分は3つ：**PD-M（マネジメント）／PD-D（データ・AI）／PD-S（システム）**
- 2027年度開始予定（実施は**夏〜秋頃**）
- 「応用情報の後継」ではなく、**高度試験の統合先**という性格が強い

### 見直しの背景（経産省・IPA）

- 「DX推進、AI活用に必要となるデジタル技術やデータ活用は進化しており、これに対応するスキルも変化している」
- 出発点は経産省「**Society 5.0時代のデジタル人材育成に関する検討会 報告書**」（2025年5月）
- 実務上の含意：**細分化された専門資格を、より大きな「役割」単位に再編する**方向

---

## 2. 新試験体系（8区分）の中での位置

| 新区分 | 扱い | 現行との関係 |
|---|---|---|
| ITパスポート試験 | 継続（内容変更） | IP |
| **データマネジメント試験**（仮称） | **新設** | 該当なし（新領域） |
| 情報セキュリティマネジメント試験 | 継続 | SG |
| 基本情報技術者試験 | 継続 | FE |
| **PD（マネジメント）試験**（仮称） | **新設** | 高度試験の統合先 |
| **PD（データ・AI）試験**（仮称） | **新設** | 同上 |
| **PD（システム）試験**（仮称） | **新設** | 同上 |
| 情報処理安全確保支援士試験 | 継続（一部変更） | SC |
| ~~応用情報技術者試験~~ | **廃止** | PD試験3区分へ再編・統合 |

> **注目点**：**基本情報技術者試験（レベル2）は残る**が、**応用情報（レベル3）だけが消える**。
> レベル2の次がいきなりPD試験（レベル4相当と読める）になる構造。

## 3. 3区分それぞれの中身

### 3.1 PD-M：プロフェッショナルデジタルスキル（マネジメント）試験

**概要（IPA原文）**
> 組織やビジネスにおける、データ及びデジタル技術を利活用するプロセスを**マネジメントする**専門的な知識及び技能が、目標とする水準に達していることを評価する。

**科目B（技能）の出題範囲**

1. **組織及びビジネスの変革・デジタル戦略に関すること**
   外部環境／内部環境・ステークホルダのニーズ分析、ビジネスモデル及びビジネスプロセスのデザイン、ポートフォリオ及びプログラムのマネジメント、SoE（System of Engagement）の活用、イノベーションマネジメント、システム思考・デザイン思考
2. **サービスマネジメントに関すること**
   事業関係管理、サービスレベル管理、供給者管理、変更管理、リリース及び展開管理、サービスデスク、インシデント管理、問題管理、サービス可用性管理、サービス継続管理
3. **プロジェクトマネジメントに関すること**
   変化への適応・不確実性への対応・価値創出、プロジェクト組織／チーム／メンバーのマネジメント、立ち上げ〜計画〜実行・管理〜終結
4. **組織のガバナンス・監査に関すること**
   ガバナンス・マネジメント・内部統制の構築と運用に関する助言、デジタル環境の企画〜運用〜利用プロセスの監査、情報セキュリティ・**新技術（AIほか）の利活用に関する監査**

> **現行でいえば**：プロジェクトマネージャ＋ITサービスマネージャ＋システム監査技術者＋ITストラテジストの一部を束ねた領域（**推測**。IPAの明示的な対応表は未確認）

### 3.2 PD-D：プロフェッショナルデジタルスキル（データ・AI）試験

**概要（IPA原文）**
> 組織やビジネスの**データドリブンな活動を支える基盤を構築してデータを整備する**専門的な知識及び技能が、目標とする水準に達していることを評価する。

**科目B（技能）の出題範囲**

1. **データマネジメントに関すること**
   データ戦略・組織戦略、データアーキテクチャ、データガバナンス、データ定義の標準化、メタデータ整備・データ品質の評価と改善、データのトラスト管理、データ流通
2. **データ・AIの活用に関すること**
   分析目的の設定と設計、集計・分析・可視化・レポート作成（BIツール等 SoI の活用）、統計学・機械学習・時系列解析、**データ生成・マルチモーダル・RAG・AIエージェントなど生成AI技術の適用**、**AI倫理**
3. **データエンジニアリングに関すること**
   正規化等に基づくデータ分析、概念・論理・物理データモデルの作成、データ統合・変換、**データ基盤／データパイプラインの設計・構築・運用（クラウド活用を含む）**
4. **データ処理とアルゴリズムに関すること**
   CRUD操作、データ構造とプログラミング、アルゴリズムとプログラミング
   - **注記：データの操作について SQL を扱う**
   - **注記：プログラム言語について 擬似言語を扱う**

> **★重要**：PD-Dは**SQLと擬似言語プログラミングが明記されている**。**コードを回避できない区分**。

> **現行でいえば**：データベーススペシャリスト＋データサイエンス／AI領域の新規部分（**推測**）

### 3.3 PD-S：プロフェッショナルデジタルスキル（システム）試験

**概要（IPA原文）**
> デジタル技術を適用するシステムの**要件定義・アーキテクチャ設計・開発・運用を主導する**専門的な知識及び技能が、目標とする水準に達していることを評価する。

**目標とするスキル水準（抜粋）**

- 業務モデリングやニーズ分析の手法を用いた要件定義と、**システム全体のアーキテクチャ設計**
- ネットワーク関連技術（光／無線通信方式、冗長化、ネットワーク／サーバ仮想化）を適用した**ネットワーク基盤の設計・構築・保守・運用**
- **フィジカルコンピューティング**（IoT、ロボティクス、組込み・制御、リアルタイム処理、セーフティ）の設計・構築・評価・維持管理
- 開発手法及びツール（**アジャイル開発、CI/CD、AIを用いた開発プラットフォームの活用**）の適用
- **レガシーシステムのリスク評価とモダナイゼーションの提案**

> **現行でいえば**：システムアーキテクト＋ネットワークスペシャリスト＋エンベデッドシステムスペシャリストを束ねた領域（**推測**）

## 4. 試験の構成 ── 現行の高度試験と同じ3科目制

| 科目 | 内容 | 範囲 |
|---|---|---|
| **科目A-1** | **共通知識** | PD試験3区分＋支援士試験で**共通**。下記30中分類すべて |
| **科目A-2** | **専門知識** | 区分ごとの専門分野のみ（→ 5節） |
| **科目B** | **技能** | 区分ごと（→ 3節） |

- 科目A-1のシラバスは「PD試験（仮称）及び情報処理安全確保支援士試験 **共通知識** シラバス（案）」として別途用意される
- 現行APの「科目A＋科目B」の2科目制ではない
- **出題形式**：IPAは新試験全体について「**CBT方式に適した多肢選択式を中心とした出題に見直す**」としている。
  ただし**PD試験のサンプル問題は2026-07-31時点で未公開**（公開済みはデータマネジメント試験のみ）。
  **科目B（技能）が具体的にどんな形式になるかは未確認**
- **試験時間・出題数・合格基準はいずれも未公表**

### 4.1 新しい科目A体系（7大分類・30中分類）

現行APの23中分類とは**まったく別の体系**に組み替えられている。

| 分野 | 大分類 | 中分類 |
|---|---|---|
| **ビジネス** | 1 ビジネス変革 | 1 ビジネス変革の方法論／2 経営戦略・デジタル戦略／3 ビジネスモデル・ビジネスプロセス／4 サービスマネジメント／5 プロジェクトマネジメント／6 デザインのアプローチ／**7 マインド・スタンス** |
| | 2 データ・AIの利活用 | 8 データマネジメント／9 データ分析・データ利活用／10 AI利活用 |
| | 3 組織活動 | 11 経営・組織論／12 ガバナンス・監査 |
| **テクノロジ** | 4 デジタル技術 | 13 デジタルサービス・デジタルツール／14 システムの種類・構成／**15 クラウド**／16 ネットワーク／17 データベース／**18 AI技術**／19 情報デザイン・情報メディア |
| | 5 システムの開発・運用 | 20 システムライフサイクルプロセス／21 開発・運用の方法論／22 アルゴリズム・プログラミング |
| **セキュリティ・倫理** | 6 セキュリティ | 23 情報セキュリティの脅威／24 情報セキュリティマネジメント／25 情報セキュリティ対策／26 セキュリティ実装技術・評価 |
| | 7 倫理・コンプライアンス | **27 情報倫理・AI倫理**／28 ビジネス関連法規／**29 プライバシー関連法規**／30 セキュリティ関連法規 |

**現行APからの構造的な変化**

| 変化 | 中身 |
|---|---|
| **新設された領域** | クラウド（15）、AI技術（18）、AI利活用（10）、データマネジメント（8）、情報倫理・AI倫理（27）、プライバシー関連法規（29）、**マインド・スタンス（7）**、デザインのアプローチ（6） |
| **格下げ・縮小された領域** | ハードウェア・プロセッサ・メモリ・バス等は「14 システムの種類・構成」に吸収。**基礎理論（離散数学・応用数学・計測制御理論）の独立した中分類が消滅** |
| **知識項目の刷新** | 18 AI技術＝機械学習、ディープラーニング、**生成AIの技術（LLM、RAGほか）、AIエージェントの技術（MCPほか）**／21 開発・運用の方法論＝アジャイル開発、DevOps、**AI駆動開発** |

> **「マインド・スタンス」（中分類7）が知識分野として入っている**のは現行にない発想。
> 変化への適応、コラボレーション、顧客・ユーザーへの共感、常識にとらわれない発想、
> 反復的なアプローチ、柔軟な意思決定、事実に基づく判断、アジャイルなふるまい ── が知識項目例。

## 5. 想定水準 ── 応用情報より明確に上

IPAの「目標とするスキル水準」の書き分けを並べると差が出る。

| 試験 | 書きぶり |
|---|---|
| ITパスポート | 「基礎知識及びマインド・スタンス」 |
| データマネジメント | 「**基本的な**知識及び技能」 |
| 基本情報技術者 | 「**基本的な**知識及び技能」 |
| **PD-M** | 「プロセスを**マネジメントする専門的な**知識及び技能」 |
| **PD-D** | 「基盤を構築してデータを整備する**専門的な**知識及び技能」 |
| **PD-S** | 「要件定義・アーキテクチャ設計・開発・運用を**主導する専門的な**知識及び技能」 |

- 「専門的な（professional）」の語が使われるのはPD試験と支援士試験のみ
- スキルの発揮場面も「**全体をリードする場面**」「主導する場面」と書かれており、**チームを率いる側**を想定
- **ただしIPAがPD試験を「レベル4」と明記した資料は確認できていない**（未確認）。
  レベル体系そのものを維持するのかも不明

## 6. 応用情報を目指す立場から見た評価

### 6.1 「応用情報の代わりにPD試験を受ければいい」とは言えない

| 論点 | 現行AP | PD試験 |
|---|---|---|
| 想定水準 | レベル3（応用的知識・技能） | 「専門的」「主導する」＝レベル4相当と読める |
| 科目構成 | 2科目 | **3科目**（A-1／A-2／B） |
| プログラミング回避 | **可能**（科目Bで問3を選ばない） | **PD-DはSQL・擬似言語が明記されており不可**。PD-M／PD-Sは未確認 |
| 記述式 | あり（科目B 5問） | 多肢選択式中心へ見直しの方針。**具体は未公開** |
| 過去問 | 20年分以上が無料で使える | **存在しない**（初年度） |

**最大の実務的な差は「過去問がない」こと。** 応用情報の学習法は過去問道場の反復が主戦場だが、
新試験の初年度受験者はサンプル問題しか手がかりがない。**独学の難度は上がる**（推測）。

### 6.2 ただし本人の適性で見ると、PD-Mは相性が悪くない

PD-Mの科目B（ビジネス変革・サービスマネジメント・プロジェクトマネジメント・ガバナンス／監査）は、
**コードを書かない領域**で構成されている。現行APで「経営戦略・サービスマネジメント・
プロジェクトマネジメント・システム監査」を選ぶ戦略と、**中身がほぼ重なる**。

> つまり「応用情報が消えたら詰み」ではない。**PD-Mは戦えなくはない**。
> ただし(1)水準が上がる (2)過去問がない (3)テクノインストラクターの受験資格として
> 読み替えられるか不明 ── という3点で、**現行APを取り切る方が明らかに有利**。
