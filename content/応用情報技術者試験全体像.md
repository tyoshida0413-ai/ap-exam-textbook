# 応用情報技術者試験（AP）全体像

> **この資料の位置づけ**
> 2026-07-30 時点の一次資料（IPA公式）を中心に作成。**「事実」「推測」「未確認」を区別して記載**している。
> 制度変更（令和8年度からのCBT移行）の直後にあたるため、受験前に必ずIPA公式で最新情報を確認すること。

> ## ⚠ 2026-07-31 追記：この試験は令和8年度で終了する
>
> **現行の応用情報技術者試験は、令和8年度（2026年度）の実施をもって廃止される。**
> 2027年度から新試験制度に移行し、応用情報と高度試験は

## 0. なぜこの試験を受けるのか（目的の整理）

この試験を検討している理由は2つあり、**どちらか一方だけでも受験の価値がある**。

### (1) テクノインストラクター（職業訓練指導員・情報処理科）の唯一の入口

→ 詳細は `勉強/テクノインストラクター/テクノインストラクター全体像.md`

- 職業訓練指導員免許（情報処理科）を、**実務経験ゼロ・学科要件不問**で目指せる唯一の手段
- 鹿児島県 別表1-2 の情報処理科「受験資格」欄に **応用情報技術者** が明記されている
- **基本情報技術者は同リストに載っておらず、受験資格を生まない**（＝FEを取っても指導員ルートは1ミリも進まない）
- 応用情報に合格すると「職業訓練指導員試験を受けることができる者」となり、
  職業大の実務経験者訓練技法習得コース＋能力審査のルートが開く

### (2) 転職市場での実利（こちらは単体で完結する）

- 検討中のフルリモートDX/AI推進系ポジション（コーポレートエンジニア・DXコンサル等）に**直接効く**
- 職業訓練指導員免許より**汎用性が高い**
- IT系の実務経験がない状態から「情報処理の基礎能力」を客観的に示せる数少ない手段

> **結論：テクノインストラクターを取るかを決めていなくても、応用情報の学習を始めることは損にならない。**
> むしろ**先に応用情報を取ってから、指導員免許を取るかを判断する**のが最も損の少ない順序。

### 3.3 ★多段階選抜方式（2026-07-31 追加・見落とし注意）

> 「**科目A試験の得点が基準点に達しない場合には、科目B試験の採点を行わずに不合格とする**」

- **科目Aで60点未満なら、科目Bは採点すらされない**
- 応用情報では科目Aが先に実施される（前期なら科目A＝10〜11月、科目B＝11〜12月）

| | 科目A | 科目B |
|---|---|---|

| 満点 | 100点 | 100点 |
| **基準点** | **60点** | **60点** |

- 両科目とも60点以上で合格

## 4. 基本情報技術者試験（FE）との関係

### 4.1 比較表

| | 基本情報技術者（FE） | 応用情報技術者（AP） |
|---|---|---|
| レベル | レベル2 | **レベル3** |
| 実施 | **通年CBT**（いつでも予約・受験可） | **年2回**の実施期間 |
| 科目A | 60問・90分・四肢択一 | 80問・150分・四肢択一 |
| 科目B | 20問・100分・**多肢選択式** | 11問中5問選択・150分・**記述式** |
| **科目Bの中身** | **擬似言語によるアルゴリズム＋情報セキュリティ。回避不可** | **問1情報セキュリティのみ必須。残り4問は自由選択＝プログラミングを回避できる** |
| 合格基準 | 各科目1,000点満点中600点（IRT方式） | 各科目60%以上 |
| 手数料 | 7,500円 | 7,500円 |
| 合格率 | 40%前後（要確認） | 20%前後 |
| **指導員免許の受験資格** | **生まない** | **生む（実務経験0年）** |

### 4.2 免除制度

- **FEに合格してもAPの科目免除はない。** 両者は独立した試験
- FEには「科目A免除制度」（IPA認定講座の修了＋修了試験合格で科目Aが免除）があるが、**APには存在しない**
- **APを受けるのにFE合格は不要**（前提条件ではない）

### 4.3 結論：FEを先に挟むべきか → **原則、不要**

理由は3点。

1. **FEは指導員免許の受験資格を生まない**（4.1）。目的に対して純粋な回り道になる
2. **AP科目Aの出題範囲はFE科目Aを包含する。** AP対策の過程でFEの範囲は自然にカバーされる
3. **★FEの方が「プログラミングを避けられない」分、むしろキツい**
   - FE科目Bは擬似言語のアルゴリズム問題が中心で**回避手段がない**
   - AP科目Bは問1のみ必須で、残り4問は自由選択＝**プログラミングを外せる**
   - 実装を生成AIに委ねている場合、**その弱点が直撃するのはFEであってAPではない**

**FEを挟む判断が合理的なケース（正直な評価）**

- AP科目Aの過去問がまったく歯が立たない場合（→ 5.1の判定方法）
- 学習継続に自信がない場合。FEは**通年受験なので近い距離にマイルストーンを置ける**
- ただしその場合も**目的はFE教材で基礎を埋めることであって合格ではない**。
  受験せず教材だけ使う選択（＝7,500円を払わない）でも目的は達成できる

**FEを挟むコスト**：7,500円＋教材5,000円前後＋学習時間100〜200時間（推定）。
加えて**AP受験が実質1回分後ろにずれる**（＝目標達成が半年遅れる）。

## 5. 学習戦略

### 5.1 【最初にやること】実力測定（費用ゼロ・所要2〜3時間）

**教材を買う前に、過去問を1回分解いて現在地を測る。**

```
[手順] 応用情報技術者試験ドットコム（過去問道場）で AP科目A を1回分（80問）解く
        ↓
     正答率 50%以上  → 基礎がかなり残っている。案A（前期）で狙える
     正答率 40〜50%  → 土台は残っている。案A挑戦可・案Bが無難
     正答率 30〜40%  → 断片的。案B（後期）
     正答率 30%未満  → ランダム水準（四肢択一の期待値25%）＝実質ゼロ。基礎固めから
```

> 判定基準の詳細と想定学習時間は **5.4(4)** を参照。
> **四肢択一なのでランダムでも25%当たる**点を必ず補正して読むこと。

- AP科目Aは**過去問からの再出題率が高い**（定説だが**要検証**）ため、この判定は実力の目安として機能する
- 総合情報学部で学んだ基礎（情報理論・アルゴリズム・DB・ネットワーク）は、
  ブランクがあっても**選択式なら想起で戻る部分が相当あると見る**（推測）

### 5.2 科目A（旧午前）対策

**テキスト通読より、過去問演習の量が効く。**

```
① 入門テキストを1周（完璧を目指さない。全体像の把握が目的）
        ↓
② 過去問道場をひたすら回す ← ここが主戦場
   ・分野別に潰す → 直近回を通しで解く
   ・間違えた問題は解説を読んで、翌日もう一度解く
        ↓
③ 正答率が安定して70%を超えたら科目Bへ比重を移す
```

- 過去問は**20年分以上（3,000問以上）**が無料で演習できる
- IPAが「**出題形式・出題数・試験時間に変更なし**」と明言しているため、
  CBT化後も過去問は引き続き最良の教材として機能する
- ただし**CBT化以降は問題の持ち帰りが不可となり、過去問の新規蓄積は止まる見込み**（推測）

### 5.3 科目B（旧午後）対策 ── 分野選択が最重要

**11問中5問選択。全分野を勉強する必要はない。**
本人の経歴を踏まえた選択案（推測）：

| 優先度 | 分野 | 理由 |
|---|---|---|
| **必須** | 問1 情報セキュリティ | 固定。全受験者が解く |
| **◎ 主軸** | 問2 経営戦略 | 営業・EC運営・法人運営の経験が読解に効く。**コード不要** |
| **◎ 主軸** | 問11 システム監査 | 文章読解と業務理解が中心。**コード不要**。福祉の記録・監査業務との親和性 |
| **◎ 主軸** | 問10 サービスマネジメント | 運用・業務改善の視点。**コード不要** |
| **◎ 主軸** | 問9 プロジェクトマネジメント | 同上。**コード不要** |
| **○ 次点** | 問6 データベース | AI駆動でのシステム構築（DB設計）経験が効く。SQLは要学習 |
| **○ 次点** | 問8 情報システム開発 | 設計・要件定義中心。構成設計の経験が効く |
| **× 除外** | 問3 プログラミング（アルゴリズム） | **回避しても合格に支障なし** |
| **× 除外** | 問7 組込みシステム開発 | 経験・関連性ともに薄い |

> **戦略**：本番での相性を考え、**6〜7分野を仕上げて当日5問を選ぶ**のが定石（推測）。
> 「経営戦略・システム監査・サービスマネジメント・プロジェクトマネジメント」の4つは
> **いずれもコード不要の文章題**であり、この4つ＋情報セキュリティで5問が成立する。

### 5.4 学習時間の目安 ── 「500時間」は自分に当てはまるのか

#### (1) 一般に言われる数値（複数ソースで一致）

| 属性 | 目安 |
|---|---|
| **情報処理技術者試験の未経験者（＝完全な初学者）** | **約500時間** |
| **基本情報合格者・IT実務経験者** | **約200時間** |
| 独学の場合 | 200〜500時間 |
| 受験指導校を使う場合 | 200〜300時間 |

- 1日2時間で500時間 → **約8か月**
- 1日2時間で300時間 → **約5か月**
- 1日2時間で200時間 → **約3.5か月**

#### (2) 本人はどちらのバケットに入るか ── **どちらでもない（中間）**

「500時間」は**ITの素地が一切ない人**を想定した数値。「200時間」は**基本情報合格者または実務経験者**。
本人はそのどちらにも該当しない。

**500時間から削れる要素（有利）**

| 要素 | 効き方 |
|---|---|
| **総合情報学部 総合情報学科卒** | 情報理論・アルゴリズム・DB・ネットワークの土台を一度作っている。**四肢択一なら想起で戻る部分が相当ある見込み**（推測） |
| **ストラテジ系20問・マネジメント系10問（計30問＝37.5%）** | 商社・広告代理店での営業／EC運営／NPO法人運営の経験が読解に効く。**ここは実質的にアドバンテージ**（推測） |
| **科目Bでプログラミングを回避できる** | アルゴリズム・擬似言語の学習コストを丸ごと省ける。初学者が最も時間を溶かす領域を通らずに済む |
| **直近のAI駆動でのシステム構築** | DB設計・構成設計・要件定義の実地経験。科目Bのデータベース／情報システム開発に効く |
| **宅建の学習経験** | 資格試験の学習法（過去問中心・回転数）を既に知っている |

**500時間から削れない要素（不利）**

| 要素 | 効き方 |
|---|---|
| **卒業から約19年のブランク** | 「知識が古い」以前に**忘れている**。想起で戻る保証はない |
| **在学当時に存在しなかった/扱いが小さかった領域** | クラウド、コンテナ、現代的な情報セキュリティ、アジャイル、AI・機械学習。**ここは完全に新規学習**になる |
| **IT実務経験ゼロ** | 200時間バケットの条件を満たさない |
| 学部の技術的深度 | 「総合情報学部」は文理融合型のことが多く、工学部情報工学科ほどの深度でない可能性（**推測・未確認**） |

> **見立て（推測）**：**300〜400時間**が現実的な中心値。
> ただし**これは推測であり、断定はできない。**

#### (3) 正直に言うと、この問いは机上では答えが出ない

**「500時間必要か」は、現在どれだけ覚えているかで決まる。**
そしてそれは**過去問を1回分解けば2〜3時間で判明する**（5.1）。

議論に時間を使うより測った方が早く、かつ正確。**教材を買う前にこれをやる。**

#### (4) 実力測定の判定基準（改訂版）

> **重要な前提**：科目Aは**四肢択一なので、完全にランダムでも25%は当たる。**
> したがって「正答率30%」は**ほぼ知識ゼロ**を意味する。この補正を入れて判定する。

| 正答率 | 解釈 | 想定学習時間 | 推奨スケジュール |
|---|---|---|---|
| **50%以上** | 基礎がかなり残っている。合格ライン60%まであと少し | 200〜300時間 | **案A（前期）で十分狙える** |
| **40〜50%** | 土台は残っている。穴を埋める作業 | 300〜400時間 | 案A挑戦可。**案Bが無難** |
| **30〜40%** | 断片的に残っている程度 | 400〜500時間 | **案B（後期）** |
| **30%未満** | ランダム水準＝**実質ゼロからの再スタート** | 500時間以上 | 案Bでも厳しい。**2027年後期以降**を見据える。FE教材での基礎固めを併用 |

#### (5) 時間の総量より「継続」が律速になる

率直に指摘しておく。

- 500時間か300時間かの差（約100日 vs 約150日／1日2時間換算）よりも、
  **1日2時間を数か月continuously維持できるかどうか**の方が、実際には合否を分ける
- **宅建の学習が中断している**という事実がある以上、ここは楽観視すべきでない
- 対策として有効と考えられるもの（推測）
  - **科目Aと科目Bの実施期間が分かれている**利点を使い、**まず科目Aだけに集中する**
    （目標が近くなり、達成感を得やすい）
  - 過去問道場は**進捗と正答率が可視化される**ため、宅建より継続の手応えを得やすい
  - 1日2時間が維持できないなら、**期間を延ばす前提で計画を立て直す**（案Bまたは2027年後期）

## 10. 【重大】令和9年度（2027年度）からの新試験制度 ── 現行APは令和8年度で終了

*2026-07-31 調査で判明。1.2.0 までのこの資料には記載がなかった。*

### 10.1 事実（IPA公式）

- IPAは「**現行試験制度については、2026年度の試験実施をもって終了し、2027年度から新試験制度に移行する予定**」と明記している
- 新制度では試験区分が8区分に再編され、**応用情報技術者試験と高度試験は「大括り化」されて統合・廃止**される

**新試験制度の区分（2027年度開始予定）**

| 区分 | 扱い |
|---|---|
| ITパスポート試験 | 継続（内容変更） |
| 情報セキュリティマネジメント試験 | 継続 |
| 基本情報技術者試験 | **継続** |
| データマネジメント試験 | 新設 |
| **プロフェッショナルデジタルスキル（マネジメント）試験** | 新設 |
| **プロフェッショナルデジタルスキル（データ・AI）試験** | 新設 |
| **プロフェッショナルデジタルスキル（システム）試験** | 新設 |
| 情報処理安全確保支援士試験 | 継続（一部変更） |
| **応用情報技術者試験** | **廃止**（上記3区分に再編・統合） |

- 出題形式は **CBTに適した「多肢選択式」中心に見直される**（＝**記述式の科目Bは無くなる方向**）
- 実施時期は、新制度の**プロフェッショナルデジタルスキル試験群は夏〜秋頃**の予定
- 経過措置：現行高度試験・支援士試験の科目免除要件を満たした者には、一定期間の部分免除を検討中

### 10.2 受験計画への影響（重要）

1. **現行APを受けられるのは、令和8年度の前期・後期の合計2回だけ**
   - 案A（前期／2026年10〜12月）
   - 案B（後期／2027年2〜3月）
   - **案Bで不合格なら、現行APでの再挑戦はできない**（推測。→ 8章 未確認事項8）
2. **「案Bが堅実」という7章の評価は、前提が変わった**
   - 従来は「落ちても半年後に再受験できる」前提での堅実案だった
   - 実際には**案Bは後がない一発勝負**になる。堅実さの意味が変わる
   - **合理的なのは「案Aで1回受け、落ちたら案Bで取り返す」＝2回受験を前提に組む案**（推測）。
     受験料は1回7,500円、2回で15,000円
3. **テクノインストラクターの受験資格への影響が読めない（最重要の未確認事項）**
   - 鹿児島県 別表1-2 は「**応用情報技術者**」を名指ししている
   - その試験が廃止された後、**後継区分が同等資格として読み替えられるかは不明**
   - **現行APを令和8年度中に取っておけば、この不確実性を丸ごと回避できる**
   - → 職業能力開発総合大学校・鹿児島県への照会時に、**この論点も併せて確認すべき**

> **率直な評価**：この事実は「応用情報を受けるか」の判断そのものを変える性質のものではない
> （取る価値は変わらない）。変わるのは**タイミング**で、**「いつか受ける」という選択肢が消えた**。
> 令和8年度に取るか、新制度の別試験に切り替えるかの二択になる。

> **★新試験そのものの詳細は別ノートに分離した（2026-07-31）**
> `プロフェッショナルデジタルスキル試験_調査.md`
> 3区分（マネジメント／データ・AI／システム）の内容、3科目制の構成、新しい科目A体系
> （7大分類・30中分類）、区分ごとの専門分野、未確認事項をそちらに収録。

### 10.3 新試験は「傾向が変わる」のではなく「別の試験になる」（2026-07-31 追加調査）

IPAが公開している **プロフェッショナルデジタルスキル（システム）試験 シラバス（案）Ver.0.2**
（2026-06-30公開・2026-07-31更新）および「出題範囲等の改定案」を確認した結果、以下が判明した。

#### (1) 科目構成が変わる ── 応用情報の2科目制ではなく、高度試験と同じ3科目制

| | 現行AP | 新・PD試験 |
|---|---|---|
| 科目構成 | 科目A（知識）＋科目B（記述） | **科目A-1（共通知識）＋科目A-2（専門知識）＋科目B（技能）** |
| 位置づけ | 独立した2科目 | **現行の高度試験・支援士試験と同じ構成** |

- 科目A-1は「PD試験＋支援士試験の**共通知識**」として全区分共通のシラバスが別途用意される
- 科目A-2は区分ごとの**専門知識**、科目Bは**技能**を問う

#### (2) 想定水準が上がる ── レベル3の受け皿が消える

IPAの「目標とするスキル水準」の書きぶりを並べると差が明確に出る。

| 試験 | 書きぶり |
|---|---|
| ITパスポート | 「基礎知識及びマインド・スタンス」 |
| 基本情報技術者 | 「**基本的な**知識及び技能」 |
| **PD（システム）** | 「システムの要件定義・アーキテクチャ設計・開発・運用を**主導する専門的な**知識及び技能」 |

- 現行APは**レベル3**（基本情報＝レベル2、高度＝レベル4）
- 新体系ではPD試験が**高度試験の統合先**であり、記述は明確にレベル4寄り
  → **基本情報とPD試験の間にあった「レベル3の受け皿」が無くなる**（**推測**。IPAが
  PD試験を「レベル4」と明記した資料は確認できていない）

#### (3) 出題範囲の中身が実務・設計寄りになる

PD（システム）シラバス案の科目Bは「**目標とする技能**」として、次のような**実務スキル**を列挙している。

- 組織のデジタル戦略を踏まえた業務要件の定義、システム化計画の立案
- ネットワーク基盤の設計・構築・保守・運用（冗長化、ネットワーク／サーバ仮想化）
- フィジカルコンピューティング（IoT、ロボティクス、組込み・制御、リアルタイム処理）
- アジャイル開発、**CI/CD、AIを用いた開発プラットフォームの活用**
- **レガシーシステムのリスク評価とモダナイゼーションの提案**

科目A-2（専門知識）側も、DX戦略・**エンタープライズアーキテクチャ（TOGAF、ザックマン
フレームワーク）**・契約形態（タイムアンドマテリアル、レベニューシェア、グラントバック）など、
**現行APより一段実務に踏み込んだ用語**が並ぶ。

> つまり「応用情報の範囲が少し変わる」のではなく、**現行のシステムアーキテクト＋ネットワーク＋
> エンベデッド＋開発系の高度試験を束ねたもの**が新しい試験になる。
> **現行APの学習がそのまま通用する試験ではない**（ただし科目A-1の共通知識部分は重なる見込み・推測）。

#### (4) 出題形式は「多肢選択式中心」へ

- IPAは新試験について「**CBT方式に適した多肢選択式を中心とした出題に見直す**」としている
- **現行APの科目B（記述式5問）に相当するものは、形を変える見込み**
- ただし**PD試験のサンプル問題はまだ公開されていない**（2026-07-31時点で公開済みは
  データマネジメント試験のみ。他区分は「2026年度夏頃を目途に順次」）
  → **科目Bが多肢選択になるのか、別形式なのかは現時点では確認できない（未確認）**

#### (5) 「記述式が苦手なら新試験の方が楽では」とは言えない

多肢選択式化は一見有利に見えるが、**問われる水準自体が上がる**（(2)(3)）。
さらに**現行APで使える最大の武器＝「科目Bでプログラミングを回避できる」構造が、
新試験で維持される保証はない**。PD（システム）は名前のとおりシステム開発が主戦場であり、
**回避ルートが用意されている根拠は現時点で何もない**（未確認）。

### 10.4 合格してしまえば実績は消えない

- 試験区分が廃止されても、**「応用情報技術者試験 合格」という事実と合格証書は消えない**
- テクノインストラクターの受験資格（鹿児島県 別表1-2）は「**応用情報技術者**」を名指ししているため、
  **令和8年度中に合格しておけば、新制度への移行による不確実性を丸ごと回避できる**
  （※県の別表が将来改正される可能性は残る。**未確認**）
- 逆に取れなかった場合、**新区分が資格要件として読み替えられるかは完全に不明**（8章 未確認事項7）

> **結論**：「今年度で取り切る」ことの価値は、この調査でむしろ**上がった**。
> 落ちた場合の代替ルート（新試験）は、**難易度が上がり・範囲が変わり・回避戦略が使えるか不明**
> という三重の不利を抱える。
