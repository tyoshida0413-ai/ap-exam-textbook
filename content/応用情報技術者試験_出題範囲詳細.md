## 0. 【最重要】この範囲が使えるのはいつまでか

- **現行の応用情報技術者試験は、令和8年度（2026年度）の実施をもって終了する**（IPA公式）
- 2027年度から新試験制度へ移行し、応用情報＋高度試験は
  **「プロフェッショナルデジタルスキル試験」（マネジメント／データ・AI／システムの3領域）** に再編される
- **つまり現行APを受験できるのは、令和8年度の前期・後期の合計2回のみ**
- → 詳細と受験計画への影響は `応用情報技術者試験全体像.md` の 10章を参照

**適用シラバス**：応用情報技術者試験（レベル3）シラバス **Ver.7.2**（2026年1月8日公開）
　Ver.7.1 → 7.2 の変更点は「下請法」の削除と「**中小受託取引適正化法**」の追加（法令名の改称による）。
　※市販教材の多くは「Ver.7.1対応」と表記されているが、差分はこの1点のみのため実害は小さい（推測）。

## 1. 出題範囲の全体構造

IPAの出題範囲は **4階層** で構成される。

```
分野（3つ）           テクノロジ系／マネジメント系／ストラテジ系
  └ 大分類（9つ）      基礎理論、コンピュータシステム、技術要素 …
      └ 中分類（23）   1 基礎理論、2 アルゴリズムとプログラミング …
          └ 小分類     1 離散数学、2 応用数学 …
              └ 知識項目例（実際に問われる用語・概念）
```

- **応用情報技術者試験は、23の中分類すべてが出題範囲**（「○」）
- 高度試験にある「◎＝重点分野」の指定は**応用情報にはない**。つまり**全分野が等しく対象**
- 一般に言われる「23分野」は、この**中分類**を指す

> 古い教材・Webサイトは旧名称のままのことがあるため、目次が一致しなくても慌てないこと。

### 科目Aの分野別出題数

| 分野 | 出題数 | 割合 |
|---|---|---|
| テクノロジ系 | 50問 | 62.5% |
| マネジメント系 | 10問 | 12.5% |
| ストラテジ系 | 20問 | 25.0% |
| **合計** | **80問** | 100% |

> **事実と推測の区別**：この分野別出題数は **IPA試験要綱には明記されていない**。
> 要綱が分野別出題数を定めているのはITパスポート試験のみ。
> 上表は**過去問実績に基づく通説**（応用情報技術者試験.com 等）であり、**IPAの保証ではない**。
> 実務上は安定しているが、「必ず20問ストラテジが出る」と断定はできない点に注意。

| 問4 | システムアーキテクチャ | 選択（○） |
| 問5 | ネットワーク | 選択（○） |
| 問6 | データベース | 選択（○） |
| 問7 | 組込みシステム開発 | 選択（○） |
| 問8 | 情報システム開発 | 選択（○） |
| 問9 | プロジェクトマネジメント | 選択（○） |
| 問10 | サービスマネジメント | 選択（○） |
| 問11 | システム監査 | 選択（○） |
| | **出題数 11問 → 解答数 5問（問1必須＋問2〜11から4問選択）** | |

> **読み取れること**
> - 問2は「経営戦略」1分野ではなく、**ストラテジ系3分野のどれが出るか当日まで分からない**。
>   → 経営戦略のつもりで準備していたら「情報技術の動向」や「ロジカルシンキング」が来る可能性がある。
>   **問2を主軸に据えるなら、3分野すべてを射程に入れる必要がある**（対策範囲がやや広い点に注意）
> - 問番号と分野の対応は**要綱の別紙で固定されている**。当日の並び順は予測可能

## 4. 採点・合格基準（試験要綱より）

| 項目 | 科目A | 科目B |
|---|---|---|
| 試験時間 | 150分 | 150分 |
| 出題形式 | 多肢選択式（四肢択一） | 記述式 |
| 出題数／解答数 | 80問／80問 | 11問／5問 |
| 配点 | 各1.25点 | 問1＝20点、問2〜11＝各20点 |
| 満点 | 100点 | 100点 |
| **基準点** | **60点** | **60点** |

- **両科目とも60点以上**で合格（片方だけでは合格にならない）
- **試験結果に問題の難易差が認められた場合、基準点を変更することがある**（要綱4章(4)）
- 応用情報では**科目Aと科目Bを別日に実施する**（要綱の注記に明記）

### ★多段階選抜方式（見落とし注意）

> **「科目A試験の得点が基準点に達しない場合には、科目B試験の採点を行わずに不合格とする」**（試験要綱4章(6)）

- つまり**科目Aで60点未満なら、科目Bは採点すらされない**
- 科目Aは科目Bより先に実施されるため、**科目Aを固めきらないまま科目Bを受験しても意味がない**
- → 学習配分として **「まず科目Aを確実に60点超へ」** が構造的に正しい（既存の学習戦略と整合）

### 免除制度

- 応用情報技術者試験そのものに**科目免除はない**
- 逆に、**応用情報に合格すると、高度試験・支援士試験の科目A-1（旧・午前Ⅰ）が合格後2年間免除される**

## 5. 本人の戦略に対する含意（この範囲表から読めること）

### 5.1 科目Aは「全23中分類が範囲」＝ヤマを張れない

応用情報には重点分野（◎）の指定がない。80問が23中分類に分散するため、
**捨て分野を作ると失点が積み上がる**構造。ただし1問1.25点なので、
**苦手分野を数問落としても致命傷にならない**（20問落として60点＝ちょうど基準点）。

### 5.2 ストラテジ系・マネジメント系の中身は「ITの知識」ではない

中分類19〜23（経営戦略手法・マーケティング・企業活動・法務）の知識項目例を見ると、
**SWOT分析、PPM、バリューチェーン、LTV、損益分岐点、財務諸表、労働基準法、著作権法**など、
**IT実務経験の有無と関係なく積める領域**が大半を占める。既存資料の「30問（37.5%）はアドバンテージ」
という見立ては、範囲の中身からも裏付けられる（ただし**得点できるかは学習量次第**であり、
経験があるだけで解けるわけではない）。

### 5.3 科目Bの「コード不要4分野」は範囲としても確認できる

| 問 | 分野 | 範囲の性質 |
|---|---|---|
| 問2 | 経営戦略／情報戦略／戦略立案 | **数値計算（会計・財務、事業価値評価）が含まれる点に注意** |
| 問9 | プロジェクトマネジメント | 日程計算・見積手法など**計算問題あり** |
| 問10 | サービスマネジメント | ほぼ文章題。**運用・業務改善の理解が中心** |
| 問11 | システム監査 | ほぼ文章題。**監査手続・統制の理解が中心** |

> 「コード不要＝計算不要」ではない。問2（会計・財務／事業価値評価）と問9（見積・日程）は
> **電卓なしの数値計算が出る**。既存資料5.3の分野選択案は維持できるが、
> **問2・問9は計算対策が必要**という補正を加えておく。

### 5.4 19年のブランクで「完全に新規」となる項目（範囲表から特定）

以下は2007年頃の情報系学部にほぼ存在しなかった、または扱いが小さかった項目。
**知っている前提で飛ばさず、明示的に学習時間を割り当てるべき領域**。

- **AI関連**：機械学習、ディープラーニング、生成AI、説明可能なAI、ハルシネーション、AI利活用の原則、特徴量エンジニアリング（中分類1・21・22）
- **クラウド／仮想化**：クラウドコンピューティング、SaaS/PaaS/IaaS、コンテナ、仮想化、SDN/NFV（中分類4・10・17）
- **現代セキュリティ**：ランサムウェア、標的型攻撃、多要素認証・パスワードレス認証、OAuth、SAML、CSIRT、SIEM、WAF、CVSS、ゼロトラスト的な多層防御（中分類11）
- **開発手法**：アジャイル開発、DevOps、ローコード/ノーコード、デザインパターン、アーキテクチャパターン（中分類12・13）
- **UX**：UXデザイン、人間中心設計、CXデザイン、サービスデザイン（中分類7・19）
- **データ利活用**：データサイエンス、ビッグデータ、データの可視化、統計的バイアス、認知バイアス（中分類9・22）
- **最近の法令・制度**：情報流通プラットフォーム対処法、中小受託取引適正化法（旧・下請法）、個人情報保護法の現行版、ESG投資、DX、カーボンニュートラル（中分類21・22・23）

> 逆に、**離散数学・データ構造・OS・DB正規化・OSI参照モデル・TCP/IP** といった基礎領域は
> 当時から変わっていない。ここは想起で戻る可能性が高い（推測）。**実力測定はこの二極の切り分けに使う。**
